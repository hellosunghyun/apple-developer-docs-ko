init(language:revision:)
========================

model parameter를 생성합니다.

macOS 10.15+

    init(
        language: NLLanguage? = nil,
        revision: Int = 1
    )

[parameter](https://developer.apple.com/documentation/createml/mlwordembedding/modelparameters-swift.struct/init(language:revision:)#parameters)

--------------------------------------------------------------------------------------------------------------------------------------------------

`language`

word embedding에 사용하는 text의 언어입니다.

`revision`

word embedding의 revision입니다.

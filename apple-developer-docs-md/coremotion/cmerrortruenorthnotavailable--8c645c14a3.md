CMErrorTrueNorthNotAvailable
============================

이 device에서는 진북을 사용할 수 없습니다.

iOS 4.0+iPadOS 4.0+Mac Catalyst 13.0+macOS 10.15+visionOS 1.0+watchOS 2.0+

    var CMErrorTrueNorthNotAvailable: CMError { get }

[논의](https://developer.apple.com/documentation/coremotion/cmerrortruenorthnotavailable#Discussion)

-----------------------------------------------------------------------------------------------------------

이 error는 보통 device의 위치를 아직 사용할 수 없음을 나타냅니다.

CMErrorNotAuthorized
====================

app에 Core Motion framework를 사용할 authorization이 없습니다.

iOS 4.0+iPadOS 4.0+Mac Catalyst 13.0+macOS 10.15+visionOS 1.0+watchOS 2.0+

    var CMErrorNotAuthorized: CMError { get }
